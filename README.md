# SWYNEX Exploratory Data Analysis

## Project Overview

This project was completed as part of my internship with SWYNEX Technologies.

The objective of this task was to perform Exploratory Data Analysis (EDA) on the cleaned dataset using Microsoft Excel 
and identify important trends, patterns, and business insights.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Cleaning
* Exploratory Data Analysis

## Analysis Performed

The Excel workbook includes:

* Cleaned Dataset
* Data Quality Summary
* EDA Analysis
* Pivot Tables
* Pivot Charts
* Key Insights

## Key Findings

1. Technology generated the highest sales and profit among the categories.
2. The West region generated the highest sales and profit.
3. Overall sales showed growth over the analyzed years.
4. The Consumer segment contributed the largest share of sales.
5. The analysis identified important patterns in sales, profit, categories, regions, and shipping performance.
